# Tests AMOS actifs — R45 `Aga Image Draw` (WinUAE Gate B en attente)

**Unique test courant :** [`M16_R45_IMAGE_DRAW_01.asc`](M16_R45_IMAGE_DRAW_01.asc). Installer la [bibliothèque candidate R45 v0.12.0](../../dist/AMOSPro_AGA.Lib) à la place de l'ancienne uniquement pour l'essai, puis importer l'ASC via **Project → Merge ASCII** dans AMOS interprété/WinUAE. Mettre la [banque AGAPIC `M16_AGAPIC_SAMPLE_BANK10.abk`](../design/M16_AGAPIC_SAMPLE_BANK10.abk) dans le répertoire courant Amiga. **Attention : `Load` remplace la banque AMOS 10.**

**R45 : Gate A CPU/CI PASS (127 cas natifs 68000, export source strict) ; Gate B WinUAE ÉCHEC observé (12/11/2026 : tous les retours Image Draw = 0, aucun pixel affiché)**, [CI validée](https://github.com/anthea176/AMOSPro-AGA-Extension/actions/runs/43218082112). **Un test diagnostique de la même commande est désormais actif** : il affiche la longueur native, le numéro, les flags et le nom réel de la banque pour comprendre le refus précoce. Sur l'écran AGA **320×256×16 couleurs**, vérifier trois images (opaque, masque, masque à X décalé), les quatre cas de clipping, le pixel **index couleur 0 opaque** (couleur rose), la préservation du décor sous les zones masquées, puis le retour normal à AMOS. Résultats attendus : `OPAQUE 1 MASK 1 SHIFT 1`, `CLIP 1 1 1 1`, `BAD 0 0 0 OUT 1`, `SWAP 1 BACKSAFE 1`, `NOSCREEN 0 CLOSED -1`, `RESULT 1`, `CLOSE RETURNED`. Lire les valeurs Chip avant/après, sans les prendre seules comme preuve d'absence de fuite.

**R44 v0.11.5 est toujours `LAST_GOOD`** ([bibliothèque gelée](../../dist/AMOSPro_AGA_LAST_GOOD.Lib)) ; son [test original](../passed/M15BIS_R44_MOUSE_CURSOR_01.asc) est archivé sans retouche. Ne pas promouvoir R45, ni déplacer son test en `passed/`, avant correction et validation explicite du rendu WinUAE par l'utilisateur. Gates C (AMOS Compiler) et D (Amiga AGA réel) non testées.
