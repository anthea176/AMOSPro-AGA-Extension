## Limites et décision

1. Le `LIB_SHA256` des logs est **une étiquette constante de l'ASC**, pas une mesure indépendante du binaire chargé. La SHA réelle est garantie côté dépôt GitHub, pas prouvée par les journaux WinUAE.
2. La capture fixe montre une étape au décor lisible avec un objet, **sans défaut graphique évident**, mais ne démontre pas à elle seule l'absence de traînées pendant les 405 frames. L'auteur fournit les journaux d'exécution ; pas de vidéo.
3. Les tests de Bobs ne prouvent pas de vitesse de rendu : `RETRY_VBL` est informatif.
4. **Gate C vrai AMOS Compiler P1a : NON TESTÉE. Gate D Amiga physique : NON TESTÉE.**

**Verdict : Gate B P1a Runtime = PASS fonctionnel d'après deux journaux de passages WinUAE et une capture ponctuelle.** Les 110 contrôles Gate A restent une preuve distincte. Le jalon **M19 P1b Hot Spot** démarre **source-only**, sans remplacer ni la candidate active P1a ni `LAST_GOOD` P0.
