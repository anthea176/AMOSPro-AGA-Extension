# M19 P0i — rendu privé de Bobs persistants multi-banques

**Cible MC68020+ ; code source sur `main`, Gate A MC68020 **PASS (76 vérifications)**, [CI M19 44163799991](https://github.com/anthea176/AMOSPro-AGA-Extension/actions/runs/44163799991).** Cette étape reprend exactement P0h (SHA256 `2c5c371754a3b54c797c7b413769ef2536db92cdad7eba3db8185bb88dea7782`), les routines P0c de préparation/cache Chip, le Blitter P0d Safe/WaitBlit et P0f/P0g d'identité des banques.

## Raccordement

Une routine privée `routed_paint_all_entry` lance d'abord **P0h sur tous les 64 objets**. Pour chaque Bob actif dans l'ordre 1..64, `routed_paint_one_entry` revalide la banque enregistrée, effectue `Bnk.GetAdr` sur **cette banque** plutôt que sur le choix courant, la prépare dans le cache Chip indépendant par banque si nécessaire, arme le callback End et peint synchroniquement dans le **back buffer Safe** via `safe_bank_blit_entry`, puis restaure la sélection privée originale. Ni nouvelle banque AMOS, ni `Aga Swap` implicite.

**Attention :** la route P0i expérimente une **projection temporaire du shadow privé `bank_active_state`**, restaurée sur tous les chemins de sortie. Le choix de banque utilisateur n'est pas changé de manière persistante, mais la méthode est **non réentrante** : aucun appel BOBS concurrent/interruption pendant la projection. Ce n'est pas encore le contrat définitif de `Aga Bob Draw`. Il faudra soit prouver l'absence de réentrance, soit fournir un chemin explicite par banque sans projection.

## Gate A ciblée

[Émetteur](../tools/m19_p0i_multibank_draw_emit.py), [builder source-only](../tools/build_m19_p0i_multibank_draw_in_memory.py), [test MC68020 pixel-exact](../tools/test_m19_p0i_multibank_draw_gate_a.py). Le banc exécute **deux placements mémoire natifs AP20 V2 simulés** (interpréteur et Compiler) avec les véritables instructions MC68020. Il valide le rendu **pixel-exact** des banques 10 et 11, ainsi que **64 Bobs actifs**, répartis en 32+32, y compris les recouvrements et l'ordre 1…64. Il vérifie le cache Chip sans nouvelles allocations inutiles, le front inchangé, l'absence de Swap, la restauration de la sélection sur les chemins de succès/échec, le refus d'une génération périmée (également pour le 64e Bob), le SafePort non prêt et la libération par Close. Le cas **image 4096 absente dans la banque du 64e Bob** doit rendre un échec, sans présentation du back buffer partiel.
