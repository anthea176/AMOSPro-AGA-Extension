Les images 32×32 sont **des silhouettes asymétriques**, construites en mémoire et capturées en AGBO 3/4 ; les images AMAL 16×16 restent AGBO 1/2. Un seul écran AGA privé, double buffer et banque AGBO 24. Les banques 27 (sonde C Block 8×1) et 28 (tampon AMAL de 16 octets) restent indépendantes. Aucun fichier graphique externe.

**Swap non bloquant :** si `Aga Swap` refuse la présentation dans les phases 1, 3 ou 4, le banc conserve la première erreur de présentation dans ses compteurs et tente jusqu'à 4 reprises, chacune après `Aga Wait Vbl`. Si la frame reste refusée, l'erreur est bloquante ; jamais de `Aga Bob Update` supplémentaire dans le retry.

## Contrats P2 effectivement appelés

- **P2a** : `Aga Bob Col(A,B,Mode)` numérique : 0 rectangle, 1 masque ; retour 1 contact, 0 non-contact, -1 refus.
- **P2b** : `Aga Bob Flip(N,Mode)` numérique : 0 normal, 1 horizontal, 2 vertical, 3 combiné, modes hors plage rejetés à 0.
- **P2c** : `Aga Bob Planes(N,Masque)` numérique : masque 8-bit, retour 1 accepté, 0 refus. Le masque de destination est **distinct** du masque AGBO d'opacité.
- **P2d** : `Aga Bob Auto Update(1/0)` numérique, un Update automatique avant `Aga Swap` ; 1 accepté, 0 refus.
- **P2e** : AMAL natif `Amal 0/1,_CODE$ To _ADDR`, `Synchro Off`, `Synchro` explicite, mémoire `[flags, X, Y, image]` de 8 octets par canal ; état copié dans `Aga Bob`. Pas de nouveau token AGA.

**Oracle graphique** : les pixels testés proviennent du fond de chaque page physique et de la rotation/mirror du masque AGBO, sans capturer la page actuellement affichée. Les attendus des deux grands F/L ont été simulés indépendamment pour les 4 orientations, les 5 masques et la collision (rectangle seul vs masque).

**Journaux jamais confondus avec le banc précédent :** `RAM:M19_P2_FULL_RUNTIME.TXT` (Runtime), `RAM:M19_P2_FULL_INTERPRETED.TXT` (strict), `RAM:M19_P2_FULL_COMPILED.TXT` (Compiler) et `RAM:M19_P2_FULL_UNKNOWN.TXT` (secours). Le tag `SOURCE_TAG P2_FULL_V1_20261121` identifie précisément ce test.
