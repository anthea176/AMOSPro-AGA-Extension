# RPG AGA FAST — POC de déplacement 192×192

**Version expérimentale du 15/11/2026.** Source AMOS complète en annexe, à enregistrer au format ASCII sous `RPG_MOVE_192_FAST.asc` (ou à utiliser depuis le paquet utilisateur de la conversation). Pas de modification de `tests/current/`, dont le test M19 P0b reste actif.

**Cible :** AMOS Professional, AGA PAL 320×256×256, MC68020+, commandes R84 ou API compatible. Deux ressources déjà créées pour le premier POC : `RPG_BG.iff` (82 744 octets, SHA256 `d304f8e852ee7fa38a2f7e257d18588395b26bea908b2e838bc228ba63277c9c`) et `RPG_HERO.abk` (794 octets, SHA256 `f58f4274de1d4a5eb0589db912a8f262d215cd48712d9ab274ad8293d0ca0ecd`). Elles doivent rester côte à côte. Banques 11–14 libres.

**Différence principale :** le premier programme restaurait 320×256×8 = 81 920 octets planaires à chaque mouvement. Celui-ci initialise les deux buffers une fois, puis conserve pour chacun un rectangle CBlock Chip 32×18×8. À chaque mouvement : `Restore` de 4 608 octets, `Capture` de 4 608 octets, rendu masqué 20×18, puis `Aga Swap` explicite. **9 216 octets de fond contre 81 920** par mouvement (×8,9 moins de données copiées, **pas** une mesure de FPS). Les rectangles restent dans 192×192, avec X multiple de 8. `_STEP=3` pixels/frame et sortie Échap.

**Pourquoi pas les nouvelles commandes Bob ?** La candidate M19 P0b active livre `Aga Bob Bank`, `Get AGA Bob`, `Make AGA Bob Mask` et `No AGA Bob Mask`, mais pas encore `Aga Bob N,X,Y,I` pour afficher les objets. Le POC ne doit pas prétendre utiliser un moteur de rendu absent. Les fonctions `Aga C Block` et `Aga Bank Image Draw` sont documentées/validées dans R84.

**Testé :** preflight du skill AMOS PASS ; 21 tests du préflight PASS ; modèle hôte sur 2 006 mouvements et deux buffers PASS. **NON TESTÉ :** AMOS/WinUAE Runtime, vrai AMOS Compiler, Amiga physique. Ne pas présenter ce test hôte comme une Gate B/C. Installer la bibliothèque compatible et utiliser **Project → Merge ASCII** depuis un programme vide. En cas d'erreur, relever `ERREUR`, les retours `CLOSE RETURNED` et les paramètres WinUAE.

## Source AMOS complète

```amos
' RPG AGA FAST POC - dirty CBlock per AGA back buffer.
' AGA API R84 or later. No unvalidated AGBO Bob rendering.
' 320x256x8 PAL. The HERO is AGAPIC 20x18, masked.
' Movement limited to x=0..172 and y=0..174 in 192x192.
' Key State(79/78/76/77) = left/right/up/down; ESC=69.
' Reserve free banks 11,12,13,14 (11 is temporary full BG).
' Source files: RPG_BG.iff / RPG_HERO.abk in same drawer.
' Import with AMOS Pro Project / Merge ASCII.
Set Buffer 20
Cls
Print "RPG AGA FAST - 32X18 DIRTY RECTANGLES"
Print "FLECHES = BOUGER / ESC = SORTIR"
_ERR=0 : _OPEN=0 : _DB=0 : _QUIT=0
_FRAMES=0 : _CAPS=0 : _RESTS=0 : _RETRIES=0
_CURSOR=0 : _BACK=13 : _STEP=3
_X=84 : _Y=84
If Aga Detect=0
   Print "AGA ABSENT"
   End
End If
If Length(11)<>0 or Length(12)<>0 or Length(13)<>0 or Length(14)<>0
   Print "BANQUES 11,12,13,14 DOIVENT ETRE LIBRES"
   End
End If
Print "CHOISIR RPG_BG.iff"
_BGFILE$=Fsel$("**")
If _BGFILE$=""
   Print "ANNULE"
   End
End If
If Len(_BGFILE$)<10
   Print "FICHIER INCORRECT"
   End
End If
If Right$(_BGFILE$,10)<>"RPG_BG.iff"
   Print "CHOISIR RPG_BG.iff"
   End
End If
_HEROFILE$=Left$(_BGFILE$,Len(_BGFILE$)-10)+"RPG_HERO.abk"
_W=Aga Pic Info(_BGFILE$,0)
_H=Aga Pic Info(_BGFILE$,1)
_D=Aga Pic Info(_BGFILE$,2)
_C=Aga Pic Info(_BGFILE$,7)
If _W<>320 or _H<>256 or _D<>8 or _C<>256
   Print "IFF ATTENDU : PAL 320X256X8 / 256 COULEURS"
   End
End If
' Load into bank 12; AMOS Load may raise an error if absent.
Load _HEROFILE$,12
If Length(12)<32
   _ERR=1 : Goto _CLEANUP
End If
If Peek$(Start(12),6)<>"AGAPIC"
   _ERR=2 : Goto _CLEANUP
End If
_SW=Aga Bank Image Info(12,1)
_SH=Aga Bank Image Info(12,2)
_SD=Aga Bank Image Info(12,3)
If _SW<>20 or _SH<>18 or _SD<>8
   _ERR=3 : Goto _CLEANUP
End If
_OPEN=Aga Screen Open(320,256,256,$00021000)
If _OPEN<>1
   _ERR=4 : Goto _CLEANUP
End If
_DB=Aga Double Buffer
If _DB<>1
   _ERR=5 : Goto _CLEANUP
End If
_OK=Aga Iff Load(_BGFILE$)
If _OK<>1
   _ERR=6 : Goto _CLEANUP
End If
' Capture full background ONCE for initialising both buffers.
_OK=0
For _TRY=1 To 20
   If _OK=0
      _OK=Aga C Block Capture(11,0,0,320,256,2)
      If _OK=0
         Aga Wait Vbl
         Inc _RETRIES
      End If
   End If
Next _TRY
If _OK<>1
   _ERR=7 : Goto _CLEANUP
End If
' Safe 32-pixel rectangle, aligned to 8 and INSIDE 192x192.
Gosub _RECT
' Initialisation des deux buffers avec le meme decor et personnage.
For _SIDE=0 To 1
   If _SIDE=1
      _OK=0
      For _TRY=1 To 20
         If _OK=0
            _OK=Aga C Block Draw(11,0,0,2)
            If _OK=0
               Aga Wait Vbl
               Inc _RETRIES
            End If
         End If
      Next _TRY
      If _OK<>1
         _ERR=8 : Goto _CLEANUP
      End If
   End If
   _BK=13+_SIDE
   _OK=0
   For _TRY=1 To 20
      If _OK=0
         _OK=Aga C Block Capture(_BK,_PX,_Y,32,18,2)
         If _OK=0
            Aga Wait Vbl
            Inc _RETRIES
         End If
      End If
   Next _TRY
   If _OK<>1
      _ERR=9 : Goto _CLEANUP
   End If
   Inc _CAPS
   _OK=Aga Bank Image Draw(12,_X,_Y,1)
   If _OK<>1
      _ERR=10 : Goto _CLEANUP
   End If
   _OK=0
   For _TRY=1 To 20
      If _OK=0
         _OK=Aga Swap
         If _OK=0
            Aga Wait Vbl
            Inc _RETRIES
         End If
      End If
   Next _TRY
   If _OK<>1
      _ERR=11 : Goto _CLEANUP
   End If
   Inc _FRAMES
   Amos To Back
Next _SIDE
' Both buffers now contain the actor. Only two 32x18 blocks remain.
Erase 11
_CURSOR=Aga Mouse Cursor(0)
' Next inactive AGA buffer owns the background snapshot in bank 13.
_BACK=13
Repeat
   _KEY=Aga Key
   If _KEY=$45 or Key State(69)<>0
      _QUIT=1
   End If
   _DX=0 : _DY=0
   If Key State(79)<>0
      _DX=-_STEP
   End If
   If Key State(78)<>0
      _DX=_STEP
   End If
   If Key State(76)<>0
      _DY=-_STEP
   End If
   If Key State(77)<>0
      _DY=_STEP
   End If
   ' RAWKEY event fallback when the AGA window has focus.
   If _DX=0 and _DY=0
      If _KEY=$4F
         _DX=-_STEP
      End If
      If _KEY=$4E
         _DX=_STEP
      End If
      If _KEY=$4C
         _DY=-_STEP
      End If
      If _KEY=$4D
         _DY=_STEP
      End If
   End If
   _NX=_X+_DX : _NY=_Y+_DY
   If _NX<0
      _NX=0
   End If
   If _NY<0
      _NY=0
   End If
   If _NX>172
      _NX=172
   End If
   If _NY>174
      _NY=174
   End If
   If _QUIT=0 and (_NX<>_X or _NY<>_Y)
      ' Background in this INACTIVE buffer is independent.
      _OK=0
      For _TRY=1 To 12
         If _OK=0
            _OK=Aga C Block Restore(_BACK,2)
            If _OK=0
               Aga Wait Vbl
               Inc _RETRIES
            End If
         End If
      Next _TRY
      If _OK<>1
         _ERR=12 : _QUIT=1
      Else
         Inc _RESTS
         ' Recapture fresh clean background UNDER the new position.
         _X=_NX : _Y=_NY
         Gosub _RECT
         _OK=Aga C Block Capture(_BACK,_PX,_Y,32,18,2)
         If _OK<>1
            _ERR=13 : _QUIT=1
         Else
            Inc _CAPS
            _OK=Aga Bank Image Draw(12,_X,_Y,1)
            If _OK<>1
               _ERR=14 : _QUIT=1
            Else
               _SWOK=0
               For _TRY=1 To 12
                  If _SWOK=0
                     _SWOK=Aga Swap
                     If _SWOK=0
                        Aga Wait Vbl
                        Inc _RETRIES
                     End If
                  End If
               Next _TRY
               If _SWOK<>1
                  _ERR=15 : _QUIT=1
               Else
                  Inc _FRAMES
                  If _BACK=13
                     _BACK=14
                  Else
                     _BACK=13
                  End If
               End If
            End If
         End If
      End If
   End If
   If _QUIT=0
      Aga Wait Vbl
   End If
Until _QUIT<>0
Goto _CLEANUP
' Compute clean 32x18 patch: x multiple of 8, no HUD overlap.
_RECT:
_PX=_X And 248
If _PX>160
   _PX=160
End If
Return
_CLEANUP:
If _OPEN=1
   _CUR=Aga Mouse Cursor(1)
   Aga Screen Close
   Amos To Front
End If
If Length(11)<>0
   Erase 11
End If
If Length(12)<>0
   Erase 12
End If
If Length(13)<>0
   Erase 13
End If
If Length(14)<>0
   Erase 14
End If
Cls
Print "RPG AGA FAST - FIN"
Print "FRAMES ";_FRAMES;" CAPTURES ";_CAPS;" RESTORES ";_RESTS
Print "SAFE/SWAP RETRIES ";_RETRIES
Print "ERREUR ";_ERR;" (0=OK)"
Print "CLOSE RETURNED"
End
```
