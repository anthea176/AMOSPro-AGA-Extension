## Modification du binaire

La R87 conserve le **même moteur natif de rendu groupé des Bobs** que la R86, produit par `tools/m19_bob_batch_emit.py`. Elle retire exclusivement le **diagnostic embarqué temporaire** `Aga Bob Probe` :

- Disparition du token public `Aga Bob Probe`, de son stub et de `PROBE_CODE`.
- Le bloc `BOBS` est désormais `DISPATCH_V2 + emit_bob_batch()` ; entrée à offset **0** après le dispatcher (au lieu de 20 après le témoin).
- **77 commandes publiques**, **87 entrées AP20**, quatre unités natives : `C2P` (83), `IFF` (84), `BOBS` (85), `AGA/AGAPIC` (86).
- **`Aga Bob Batch(DescriptorBank,Count)`** reste la seule nouvelle commande et l'unique commande BOBS. Index AP20 public **82**, signature `00,0` (deux arguments, retour entier). Le dernier ancien stub R84 conserve le `GetP` exigé par le Compiler.
- Les **76 signatures R84 historiques sont préservées**, de même que les trois unités de code natif historiques **octet pour octet**. Le nouveau constructeur relie exclusivement les index de groupe AP20.
- Limite **65 534 octets par unité** ; portée signée `BSR.W` et paramètres AP20 vérifiés. Aucun Swap, Wait VBL ou appel graphique en interruption introduit.

La structure de banque **`BOB1`**, ses 16 octets d'en-tête, ses descripteurs 20 octets, le clipping, les modes opaque/transparence, AGAPIC v1/v2 et FICON8 restent **identiques au [contrat R86](M19_P23_BOBS_BATCH_CONTRACT.md)**. Le backend peut laisser un back buffer partiel si une image ultérieure échoue : **ne pas faire Swap sur un résultat 0**.
