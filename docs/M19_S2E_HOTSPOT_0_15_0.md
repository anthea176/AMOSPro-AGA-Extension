## Contrat de cette tranche
- X/Y de la commande existante Aga Sprite sont l'ancre logique ; à hotspot 0, résultat identique à S2d.
- Métadonnées AGSP v1 signées sur deux WORD. Aucune modification du format, de la génération de capture ni du code de retraite.
- Un rectangle entièrement contenu dans 320x256 est exigé. Un point d'ancrage hors écran peut être valide si l'origine calculée et la totalité de l'image sont visibles. Refuser tout overflow ou rectangle partiel sans altérer la frame ni les allocations actives.
- À changement d'image, le hotspot de cette nouvelle image est utilisé. Le chemin d'échange masque les deux canaux, effectue les mêmes deux WaitTOF, puis révèle directement à l'origine cible ; le chemin de vérification/déplacement final hérité est conservé.
- À Move de même image, l'origine est calculée avec le cache du reçu, sans dépendre de la banque source éventuellement effacée.
- Format v1 inchangé. Le setter public, le clipping et les autres modes écran restent des chantiers séparés, non autorisés par ce seul travail. Le nom de version alpha.2 est un repère de développement proposé, pas une release.
