Ne jamais écrire es_wordwidth/es_flags ou FMODE. Sur V40+, aucune retouche ATTACH manuelle.

Retour D0/D1 deux pointeurs détachés (D1=0 pour simple), ou zéro/zéro. Le second échec libère le premier via l'OS. Pas de pointeur source conservé ; pas de GetExtSpriteA. ## P2b — Préparation neutre et acquisition des canaux

- [Source MC68020](../src/native/m19_s2/M19_S2D_EXT_BLANK_CHANNELS_MC68020.s) : allouer deux ExtSprite entièrement transparents de largeur commune, 1 ligne, par InitBitMap/AllocSpriteDataA ; annuler le premier si le second échoue avant acquisition. Le chemin simple réserve les deux canaux comme S2c (odd guard), sans modifier la capacité de trois objets.
- Reçu privé : GfxBase, even*, odd*, largeur, profondeur, canal pair 2/4/6, état, largeur de contexte, réservé. Avant GetExtSpriteA poser bit2 (exposition possible). Bit0/1 reçus OS confirmés ; retour -1 conserve les reçus précédents, état4/5. Retour différent du canal attendu ou incohérence ss_num => bit31 quarantaine, pas de libération spéculative. V40+ attaché demande paire par tag ; V39 attaché toujours différé dans cette étape. La lecture ss_num est celle du membre public SimpleSprite, aucun champ ExtSprite modifié.
- [Banc CPU](../tools/test_m19_s2d_ext_blank_channels_cpu.py) : ABI des appels OS, tags exacts, plans zéro, deux allocations, rollback détaché, toutes largeurs/paires et V39/40/46 selon kind, conflits, refus, erreur partielle, largeur de contexte, interdiction retry et quarantaine. Le mock de GetExtSpriteA est une hypothèse d'interface, pas une preuve des effets réels sur le mode global ou les autres canaux. L'absence de référence après un échec devra être corroborée séparément avant toute libération.
- Pas de nouveau token ni registre persistant activé. La neutralité réelle (copinit, table, listes actives et fences) nécessite l'audit spécifique ExtSprite ; ne pas réutiliser aveuglément la neutralité S2c si l'OS remplace le CopInit pendant la négociation de largeur.
