# AMOSPro AGA Extension 0.14.1 — Stability & Bug Fixes

> **Publication candidate — not released.** Exact P2d-L2b promoted to internal LAST_GOOD on 24 November 2026. Final CI, residual-risk disposition and archive verification remain required for publication.

Version 0.14.1 corrects the AGA graphics and software Bob engine introduced in 0.14.0. No new public command: **100 commands/functions, 203 AP20 entries, MC68020/68EC020 minimum**. P2d signatures and the public calling contract are unchanged.

## Fixes

- **Aga Iff Load:** acquires the Safe reply before bitmap writes; returns 0 without drawing when unavailable.
- **Aga Back Fill:** acquires Safe with up to three WaitTOF retries; does not draw if Safe remains unavailable. The instruction still has no numeric return value.
- **First B8 binding after Swap:** acquires an available Safe reply before first binding/capture; existing READY/DIRTY and Swap contracts remain unchanged.
- **Aga Screen Pattern:** corrected double-buffer bitmap selection. Writes to the Safe physical back buffer, not the displayed page, with bounded waiting. Does not swap; single-buffer behaviour is unchanged.
- Source reconstruction, version provenance and regression tooling aligned with the candidate.

## Installation

Back up the installed library and configuration. Replace AMOSPro_AGA.Lib in APSystem in the existing extension slot, save configuration, restart AMOS. Import ASCII examples through Project / Merge ASCII. Only the five C2P commands require separate c2p.library v1.9; Bob and Iff To Chunky do not require it.
