## Principe

Le pointeur root P2f/P2g est encore dans UNIT142 relogeable. Si une fermeture réussit mais laisse un record pending, il faut le retrouver même après déchargement/rechargement d'AMOS ou du programme compilé. Ne jamais perdre ce reçu ni créer une nouvelle allocation à chaque essai.

[Composant P2h](../src/native/m19_s1/M19_S1P2H_PERSIST_ROOT_MC68020.s) : registre Exec nommé **AMOSPro.AGA.AGSP.S1.root.v1**, une allocation AllocVec MEMF_PUBLIC|MEMF_CLEAR de 112 octets, indépendante des unités AP20. Il s'agit d'un SignalSemaphore V39+, puis magic AGSP + version/taille, les 16 octets de root P2f/P2g, un tag Task emprunteur, et le nom stocké dans la même allocation. Aucun callback ou pointeur de code. Offsets NDK : SS_SIZE 46, NestCount +14, Owner +40, QueueCount +44, ln_Name +10 ; magic +48, schema +52, root +56, emprunteur +72, nom +76. Références [semaphores.i](https://github.com/kusma/amiga-dev/blob/master/targets/m68k-amigaos/ndk/include_i/exec/semaphores.i), [exec_lib.i](https://github.com/kusma/amiga-dev/blob/master/targets/m68k-amigaos/ndk/include_i/exec/exec_lib.i), [autodocs Exec 2.1](https://amigadev.elowar.com/read/ADCD_2.1/Includes_and_Autodocs_2._guide/node059D.html), [Exec Semaphores](https://wiki.amigaos.net/wiki/Exec_Semaphores). FindSemaphore doit être entouré de Forbid/Permit ; AttemptSemaphore n'attend pas. AddSemaphore initialise et publie ; RemSemaphore retire du registre avant FreeVec. Pas de WaitTOF ni AllocVec sous Forbid.

## ABI interne

Entrée +0 : D0=0 rechercher seulement ; D0=1 rechercher/créer. D0 retourné = adresse de root verrouillée ou 0 ; D1=0 succès, 1 absent, 2 occupé, 3 incompatible, 4 allocation refusée, 5 paramètres/Exec invalides. Entrée +4 : A0 root verrouillée ; D0=1 relâché, 0 refus ; D1 motif. Préserve D2-D7/A0-A6. Exec V39+ et table LVO suffisante. Tous les accès au root doivent passer par Enter/Leave, en contexte task, sans verrou/Forbid hérité. Le sémaphore reste détenu pendant la transaction, mais le scheduling est autorisé. Aucun client ne peut mémoriser l'adresse déverrouillée ni utiliser ObtainSemaphore directement ; namespace privé. Refus des accès récursifs et des autres tasks pendant emprunt. Vérification Node, nom interne et magic/schema ; TypeOfMem aux extrémités ne garantit pas la taille exacte d'une allocation étrangère. Pas de promesse contre un tiers malveillant qui imite ce namespace.

Enter effectue une première recherche, puis allocation hors Forbid si nécessaire, puis une seconde recherche sous Forbid. Si un autre task a publié entretemps, abandon du candidat non publié, pas de doublon. Leave conserve le registre tant qu'un des quatre longs root est non nul. Si tous sont nuls, verrou exclusif simple et aucun waiter, RemSemaphore puis ReleaseSemaphore sous Forbid, Permit puis FreeVec exact. Aucun stockage permanent dans le cas nominal. En cas de mort forcée d'un task pendant l'emprunt : ne pas voler le verrou ni déréférencer un ancien VP, blocage borné jusqu'à récupération explicite/reset. Le cas normal End devra impérativement relâcher l'emprunt. Pending avec reçu de CloseScreen et emprunt relâché peut être retrouvé par un autre task, sans deref des anciennes identités A5/State.
